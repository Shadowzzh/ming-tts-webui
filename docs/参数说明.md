# Ming 高级参数说明

日常生成通常保持默认值即可。先选择合适的生成模式、清晰的参考录音与准确的参考文字，再考虑调整高级参数。比较效果时固定随机种子，一次只改一项。

网页的「高级参数」中，每项名称旁都有问号：鼠标悬停或键盘聚焦可查看，点击可固定，点击外部或按 Esc 关闭；手机直接点击。点击「参数手册」可阅读完整说明与常见问题；「使用指南」中也有入口。

## 参数速查

| 界面名称 / 字段 | 默认 | 控制什么 | 是否需要调整 |
| --- | --- | --- | --- |
| 引导强度 `cfg` | 2 | 对文本、参考声音和演绎条件的引导力度 | 通常不改。更大不保证更像或音质更好；需要比较时以默认值为基准小幅调整。 |
| 噪声系数 `sigma` | 0.25 | 采样过程的额外噪声强度，与温度共同作用 | 通常不改。温度为 0 时，这部分噪声为 0；仅调此项不会增加该部分变化。 |
| 采样温度 `temperature` | 0 | 额外采样噪声的随机程度 | 通常保留 0。想换读法先换种子；提高温度可能增加变化，也可能降低稳定性。温度 0 时仍有受种子控制的初始噪声。 |
| 分段目标长度 `max_length` | 24 | 按标点组织文本时的目标语义长度 | 通常不改。不是秒数，也不是整篇输入上限；完整长分句可超过目标，不会强行截断分句。开启原始文本时不参与分段。 |
| 解码步数上限 `max_decode_steps` | 1000 | 每个文本片段最多生成多少个自回归步骤，模型可提前结束 | 通常不改。不是扩散去噪步数或音质档位。读不完时先检查标点和分段，再适度提高；太低可能截断。 |
| 随机种子 `seed` | 1895 | 随机数序列 | 比较设置时固定；想试另一种演绎可换数字。跨设备、模型版本不保证完全一致。 |
| 使用参考说话人特征 `use_spk_emb` | 克隆模式开启 | 从参考录音额外提取说话人特征，辅助保留音色 | 克隆时建议开启。关闭后，有准确参考文字时仍可能使用参考音的声学提示。与零说话人特征互斥。 |
| 使用零说话人特征 `use_zero_spk_emb` | 克隆模式关闭 | 使用全零说话人向量，当前模型此分支也不使用上传参考音的声学提示 | 克隆时保持关闭，仅用于明确的实验对照。不是降噪或零样本克隆开关。内置音色、声音设计和自由指令模式自动处理此特征。 |
| 保留末尾静音 `no_trim_silence` | 关闭 | 保留每个生成片段末尾的静音；关闭时裁短较长尾静音，可能缩短拼接停顿 | 通常关闭。需要原始结尾或自行剪辑时开启。不处理开头静音，也不去背景底噪。 |
| 轻度降噪 `audio_postprocess` | 关闭 | 合成后清理部分低频与底噪，尽量保持时长和整体音量；可随声音预设保存 | 有底噪时开启并试听；若音色、尾音或齿音受影响，请关闭。与模型采样噪声参数不同。 |
| 使用原始文本 `raw_text` | 关闭 | 绕过常规文本清理和自动分段，整段直接送入模型 | 通常关闭。仅测试原始输入行为时开启，先用短文；开启后分段目标长度不生效，长文更易触及解码上限。 |

## 按问题选择

- **声音不像**：优先换清晰、单人、无背景音乐的参考录音，并检查参考文字。克隆模式保持参考说话人特征开启、零说话人特征关闭。
- **想换读法**：先换随机种子；需要更多变化时再小幅提高温度并试听。
- **语速、音调、音量或情绪不合适**：在对应生成模式中调整，不用解码步数代替语速或音质控制。
- **长段没读完**：补好标点、保持原始文本关闭、检查分段，再考虑提高解码上限。
- **句间停顿太长**：保持保留末尾静音关闭，并检查标点。
- **有轻微底噪**：先检查参考录音，可尝试「轻度降噪」。不能保证消除模型产生的全部杂音，开启后需要试听音色是否受影响。
- **不知道改乱了哪些参数**：点击「恢复模型默认参数」。

## 核对依据

对照固定上游版本 `a39b806` 的 `ming_tts.py` 的 `MingTTS.synthesize`、`frontend/text_processing.py`、`fm/CFM.py`、`fm/flowloss.py`、`model.py`，以及应用 `app/tts_wrapper.py` 的模式适配核实。以上针对当前 0.5B 运行实现，不把其他 TTS 模型的同名参数解释套用到 Ming。

网页问号与页面内手册共用 [`parameter-help.ts`](../frontend/src/lib/parameter-help.ts)；变更参数语义时应同时核对这份文档。独立部署与数据备份见 [README](../README.md)。
